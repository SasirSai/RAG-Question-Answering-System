# Vector Databases and Approximate Nearest Neighbor (ANN) Indexing

## 1. High-Dimensional Vector Search
Vector databases store dense embeddings generated by deep learning models and facilitate similarity search over billions of vectors. Exact k-nearest neighbor (k-NN) search requires computing vector distances (e.g., Cosine similarity or Euclidean distance) across the entire corpus in O(N * D) time, which is computationally prohibitive at scale. Vector databases therefore deploy Approximate Nearest Neighbor (ANN) algorithms to trade negligible recall accuracy for sub-millisecond retrieval latencies.

## 2. Hierarchical Navigable Small World (HNSW) Graphs
HNSW is the dominant graph-based ANN algorithm:
- **Multi-Layer Hierarchy:** HNSW constructs a multi-layer graph where upper layers have sparse, long-range connections (analogous to express lanes or skip-lists) and the bottom layer (Layer 0) contains all vectors with dense local connectivity.
- **Search Traversal:** Search begins at the top layer, greedily traversing nodes closest to the query vector. Upon reaching a local minimum in a layer, the search drops down to the corresponding entry point in the layer below, repeating the greedy walk until arriving at Layer 0.
- **Key Parameters:**
  - M: The maximum number of bidirectional connection links per node.
  - efConstruction: Size of the dynamic candidate list evaluated during graph construction; higher values yield better recall at the cost of indexing speed.
  - efSearch: Size of the candidate list evaluated during query execution; governs the speed versus recall trade-off.

## 3. Inverted File Index with Product Quantization (IVF-PQ)
IVF-PQ is a memory-efficient clustering and compression approach:
- **Inverted File (IVF):** The vector space is partitioned into Voronoi cells using k-means clustering. At query time, only the centroids nearest the query vector are visited (nprobe parameter), pruning the search space.
- **Product Quantization (PQ):** Decomposes D-dimensional vectors into m sub-vectors and quantizes each sub-vector to its nearest codebook centroid. Reduces 384-dimensional floating point vectors (1536 bytes) to 32-64 bytes, enabling entire indices to reside within main memory.
